# SayClear 测试用例

对照整理规则：短句看语境；多件事先归纳标题再分点（不限日程/待办）；一件事不加标题。

执行自动项：

```bash
/opt/anaconda3/bin/python3 tests/run_sayclear_cases.py
```

## C. Mac 主路径（手工）

光标先放进备忘录或任意输入框。


| ID  | 步骤                   | 期望                                        |
| --- | -------------------- | ----------------------------------------- |
| M1  | ⌘ 开始 → 说 O1 → ⌘ 或 OK | 胶囊出现；结束后只显示 Thinking；正文进当前框；不代发；无成功 toast |
| M2  | ⌘ 开始 → 说两句 → 点 X     | 不填入，输入框原样                                 |
| M3  | 不说话直接 OK             | 失败短句，不填半成品                                |
| M4  | 说完后在输入框改几个字，自己回车     | 可以改；SayClear 不代发                          |


手工项不在本次自动执行里跑，需要麦克风和辅助功能。
