# SayClear 测试用例（v0.1 可跑通版）

对照功能需求文档场景 A–E 与 §5。整理类可自动跑；录音 / 热键 / 填入需在 Mac 上手工做。

执行自动项：

```bash
/opt/anaconda3/bin/python3 tests/run_sayclear_cases.py
```

## A. 整理（转写 → 正文）


| ID  | 口述转写（输入）                                             | 期望                                       | 自动  |
| --- | ---------------------------------------------------- | ---------------------------------------- | --- |
| O1  | 帮我写一个 Python 脚本，不对，用 TypeScript，读取 CSV 然后，呃，输出 JSON。 | 只留 TypeScript；有 CSV 与 JSON；不分点；无「不对/呃」   | 是   |
| O2  | 这个页面有几个地方需要改，按钮太大了，颜色也需要调整一下，然后整体再简洁一点。              | `1. 2. 3.` 分点；含按钮、颜色、简洁；无「有几个地方需要改」套话    | 是   |
| O3  | 把这个 button 改小一点，再把 padding 调一下，那个 hover 状态的颜色太暗了。    | 分点；原样保留 button、padding、hover；不译成「按钮/内边距」 | 是   |
| O4  | 明天上午先去超市，然后下午去图书馆，晚上回来把报告写完。                         | 分点；顺序为超市 → 图书馆 → 报告                      | 是   |

## B. 客户端校验


| ID  | 输入               | 期望                | 自动  |
| --- | ---------------- | ----------------- | --- |
| C1  | 空串               | `looks_usable` 为假 | 是   |
| C2  | 正常短句             | `looks_usable` 为真 | 是   |

## C. Mac 主路径（手工）

光标先放进备忘录或任意输入框。


| ID  | 步骤                   | 期望                                        |
| --- | -------------------- | ----------------------------------------- |
| M1  | ⌘ 开始 → 说 O1 → ⌘ 或 OK | 胶囊出现；结束后只显示 Thinking；正文进当前框；不代发；无成功 toast |
| M2  | ⌘ 开始 → 说两句 → 点 X     | 不填入，输入框原样                                 |
| M3  | 不说话直接 OK             | 失败短句，不填半成品                                |
| M4  | 说完后在输入框改几个字，自己回车     | 可以改；SayClear 不代发                          |


手工项不在本次自动执行里跑，需要麦克风和辅助功能。
