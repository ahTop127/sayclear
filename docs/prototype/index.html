总流程

这一屏对应需求第 3.3 主路径、第 4 节逐步所见、第 6 节五能力流水线。用户只感知：说话 → Thinking → 输入框里出现可用正文 → 若要改，直接在输入框改。

待确认⌘ 会不会和系统或其它 App 的快捷键冲突。整理中再按 ⌘ 是取消本次还是忽略。

未录音

这一屏对应需求4.1 开始前：用户先把光标放进想填入的输入框。产品不替用户选 App。本方案：平时几乎看不见，按 ⌘ 才出现录音条。

已定入口只有全局快捷键录音；不能打字或粘贴乱口语再整理。第一期不做「打开修改」。

待确认悬浮层是否始终可见一小块，还是仅录音 / Thinking / 失败时出现。菜单栏小图标也未定，本屏故意不画。

录音中

这一屏对应需求4.2、8.1：按 ⌘ 开始后出现暗黑圆角录音条。中间是波形条纹，表示正在录音。输入框保持原样，不出现半句转写。

已定左 X = 取消这次说话（不填入、作废）。右 OK = 结束并去识别/整理，与再按 ⌘ 结束同类。当前按「按下一次开始、再按一次结束」理解（不是按住）。

待确认⌘ 与系统快捷键是否冲突；录音条出现在屏幕上的精确位置。

Thinking

这一屏对应需求4.3、8.2：结束录音后进入识别/整理。悬浮层只显示 Thinking，不要「正在整理，请稍后」。不弹确认窗，不抢当前 App 焦点。五个能力在后台自动发生，用户无感知分步。完成前不填入。

待确认Thinking 时再按 ⌘：取消本次，还是忽略。是否允许极短过渡文案：默认不要先填原文再闪成整理稿。

填入成功

这一屏对应需求4.4、5.3–5.5、场景 C（可改看场景 B）：锁定意图后的正文直接进入当前输入框。有分点就分点；不要「我理解你的需求是」。没有「已填入当前输入框」这类成功提示。SayClear 悬浮层收起。用户直接在输入框里改字、自己点发送。

已定不代发；不弹是否确认层；不做打开修改。

待确认若等待期间用户换了输入框，填「结束录音时」还是「完成时当前」的框。

失败 · 无麦克风权限

这一屏对应需求8.4：无法录音，因为系统未允许使用麦克风。录音开始时已无权限应立刻失败，不要假装在录音。输入框不填任何内容。不写系统接口名称。

待确认引导去系统设置的具体说法与按钮是否要做；本屏只用短句「去打开麦克风权限后重试」。

失败 · 没有可填入的输入框

这一屏对应需求8.4：整理已成功，但当前没有能接收文字的位置。不把正文填进错误的地方，也不填半成品。用户可点进一个输入框后再试或重录。

待确认点进输入框后如何重试写入；失败时是否提供可拷贝文稿（第一期已无「打开修改」）。

用户逐步看到什么

SayClear 是 Mac 上的悬浮工具：对着电脑说话，整理后的正文进当前任意输入框。五个能力在 Thinking 内部自动跑完，界面上不分步。要改字，直接在目标输入框改。

实线 = 已定行为 虚线 / 琥珀色 = 仍待确认
  1. 1

    把光标放进任意输入框

    AI 对话框、搜索框、备忘录都行。SayClear 不判断这是不是 AI，也不换两套模板。

  2. 2

    按 ⌘ 开始说话 第一期按键

    只有语音。不能打字或粘贴一段乱口语让产品整理。平时几乎看不见。当前按「按下一次开始、再按一次结束」理解，不是按住 Command。

  3. 3

    说话时出现暗黑圆角录音条

    布局：X · 波形条纹 · OK。波形表示正在录音。输入框里此时仍是空的（或用户原来的字），没有半句转写。点 X 取消这次，不填入。

  4. 4

    再按 ⌘ 或点 OK → Thinking

    悬浮层只显示 Thinking。不要「正在整理，请稍后」。不抢输入框焦点。用户无感知下面这条链：

    纠错（只留最后说法）→ 清洗（去掉嗯啊那个）→ 分点（有多条才拆）→ 格式化（清单或段落）→ 锁定意图并填入（不是「我理解你的需求是」）

  5. 5

    正文出现在输入框 · 无成功提示 · 不代发

    SayClear 收起。没有「已填入当前输入框」之类提示。用户自己改几个字（就在这个输入框里），自己点发送或按回车。第一期没有「打开修改」。
